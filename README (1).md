# Physics Learning Platform — 8-сынып, II тоқсан
1. **Жариялау:** `index.html` файлын GitHub репозиторийінің түбіне салып, Settings → Pages → Branch: main / root таңдаңыз; сілтеме бірнеше минутта ашылады.
2. **Мұғалім PIN-і:** әдепкі PIN — `physics8`. Өзгерту үшін жаңа PIN-нің SHA-256 хэшін есептеп, `index.html` ішіндегі `CONFIG.pinHash` мәнін ауыстырыңыз (бұзушылық саны, құлыптау уақыты, таймер де сол `CONFIG` ішінде).
3. **Құлыптың шегі:** браузер жаңа қойынды/терезе ашуды физикалық тоқтата алмайды — сайт тек оны анықтап, жазып, тапсырмаларды жасырады. Нақты емтихан үшін Safe Exam Browser немесе kiosk-режимін қолданыңыз.

## Қолжазбаны тану (✨ Жазуды мәтінге айналдыру)
Жалған тану жоқ. `CONFIG.ocr.url` бос болса — «Қолжазбаны тану қызметі қосылмаған» хабары шығады.
Қосу үшін (tpl/js1.js, CONFIG): `ocr:{url:'https://СІЗДІҢ-ПРОКСИ/recognize',headers:{},timeoutMs:20000}`.
Сайт POST JSON жібереді: `{image:'data:image/png;base64,…', lang:'kk|ru|en', format:'text+latex'}`,
жауап күтеді: `{text:'F = mg'}` (немесе `{latex:'…'}`).
API кілтін (Mathpix, Google Vision, т.б.) браузерге салмаңыз — оны тек өз серверіңіздегі прокси ішінде сақтаңыз.
Оқушы танылған мәтінді тексеріп-түзетеді, «Растау» басқанда ғана редакторға қосылады; тақтадағы қолжазба сақталады.
